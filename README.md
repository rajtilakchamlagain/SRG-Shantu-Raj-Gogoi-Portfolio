- **Motion & Clash Studies:** Clearance evaluation, revolute/prismatic joint analysis, and interference checking across working envelopes.

## 🎨 UI Architecture & Engineering Design System

This portfolio was renovated to completely replace generic "AI-generated" sci-fi tropes with a polished enterprise standard:
- **Typography:** `Plus Jakarta Sans` for clean corporate readability + `JetBrains Mono` for precise engineering callouts and telemetry.
- **Design Language:** Refined dark-slate UI (`#070b14` and `#0f172a`), subtle 32px blueprint grid background, and discreet frosted glassmorphic cards (`glass-card`).
- **Interactive Dossier Modals:** In-depth modal dialogs providing real engineering abstracts, specifications, and problem-to-solution writeups.
- **Recruiter Conversion Flow:** Sticky header, responsive mobile drawer, one-click email clipboard copy, and direct inquiry mail dispatch.

## ⚙️ Local Development Setup

Clone the repository and install dependencies:

```bash
# 1. Clone this repository
git clone https://github.com/rajtilakchamlagain/SRG-Shantu-Raj-Gogoi-Portfolio.git

# 2. Navigate to project root
cd SRG-Shantu-Raj-Gogoi-Portfolio

# 3. Install packages
npm install

# 4. Start the development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build:
```bash
npm run build
npm run preview
```
